# 非血魔法 / 非 Astral 移植验收清单

本轮按 2026-09-25 用户指令完成可移植范围，行为基线为本地上游 `../Pollution` 的 `098834e`。血魔法和 Astral Sorcery 的提供端、机器、配方及 Astral 方尖碑不在本轮范围；独立 Starstream 网络功能保留。

## 已完成范围

- 污染效果、分级、服务端权威 HUD 网络同步、GT 消声仓与爆炸污染挂钩。
- 魔力支付模拟后提交、Vis 单次扣款、连续配方状态切换、吸收器/燃料电池/供应器/导能器逻辑。
- 两种蒸馏塔逐层流体输出、1～12 层结构预览、化学浸洗池按结构补水和加工限制。
- 大型、巨型及 ZPM 魔力涡轮接入 GT 转子效率、功率、速度、耐久和多转子结构。
- 矿物提取器菜单、服务端按钮、持久化、拆除返还和原子产物插入。
- 护目镜头盔槽、翅膀胸甲槽与 GT 喷气背包物理；Curios 兼容和夜视效果。
- Starstream 查询不加载远端区块，网络身份持久化、断链释放和原子扣款。
- Alfheim/Underground 世界生成、洞穴与植被、矿脉/石团/PureTar、传送门形成及边界校验。
- 单体机器槽位和容器槽持久化；长杆材料标志、客户端天空效果、Botania Garden of Glass 风格资源。
- 文档、生成脚本、资源模型、语言文件、JEI/客户端开发检查和服务端烟测。

## 必须保持的行为不变量

- 所有资源扣款都先模拟、后提交；失败或输出仓满时不消耗输入、不凭空生成产物。
- 多层塔按实际层数路由输出，结构不完整时不运行；化学浸洗池只补足实际缺口的水。
- 涡轮必须满足完整转子数量和转子槽位，功率/效率来自 GT 机器状态，不使用独立的伪发电路径。
- 机器、容器、网络身份和能量在保存/重载后保持；拆除时按同一库存状态返还。
- 污染 HUD、传送门和 Starstream 状态由服务端决定；传送门只在有效池中消耗钻石，并遵守维度/世界边界配置。
- 自定义世界生成保持固定高度、基岩/矿层边界和原有旧区块兼容；未实现的 Astral 方尖碑不被伪造为已完成。
